1. What is/are the parent class/es of the Programmer class in the video?
- The parent classes of the Programmer class are Employee and Person. Employee is the direct parent class, while Person is the indirect parent class.

2. If you were to add a new role called Intern, where would you place it in the inheritance
hierarchy? Why?
- I would place the Intern class under Employee, at the same level as Programmer, Manager, and Cleaner. This is because an intern is also a type of employee and can inherit common attributes and methods from the Employee class.
